# Nomen

A single-file name numerology workshop after the system of Matthew Oliver Goodwin.

Your birth-certificate name is the blueprint — it never changes. The name you go by sits on top of it, and that one is yours to adjust.

Nomen reads Expression, Soul Urge, and Personality for the name you were given, then suggests **ways to wear that same name**: first only, middle as first, initials, the form you already use, and an optional extra surname. It does not invent other first names.

## Open it

- App file: [index.html](index.html)
- On a phone: open the file in Chrome or Safari, then **Add to Home Screen**.
- Needs no server. Works offline once opened.
